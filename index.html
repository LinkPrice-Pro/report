인식 가능한 헤더 예: 날짜 / 일자 / 캠페인명 / 광고비 / 총비용 / 노출수 / 클릭수 / 구매수 / 전환수 / 전환매출액 / 매출액
캠페인 성과 + 키워드/소재 상세 파일을 함께 넣어도 중복 합산하지 않습니다. 상세 파일만 올리면 해당 매체의 합계도 상세 파일에서 계산합니다. 파일별 매출·전환 집계 기준과 VAT 포함 여부는 일치시켜 주세요. 집계 일자가 없는 요약형 파일은 사용할 수 없습니다.
✓ 업로드 파일은 현재 광고주별로 로컬에 자동 저장됩니다. GitHub 연결 시 업로드 후 자동 백업이 가능합니다.

광고주 추가

광고주별로 로우데이터와 분석 결과를 별도 보관합니다. 동일한 광고주 ID를 사용하면 GitHub에서 다른 PC로 데이터를 불러올 수 있습니다.

저장 ID는 GitHub의 데이터 경로로 사용됩니다.

☁ GitHub 저장소 연결

브라우저에는 파일을 자동 저장하고, 별도의 비공개 GitHub 저장소에 원본 로우파일과 보고서 데이터를 백업합니다. 다른 PC에서 같은 광고주 ID를 선택해 복원할 수 있습니다.

🔒 주의: 공개 저장소에는 업로드할 수 없습니다. GitHub 토큰은 현재 열린 탭의 메모리에서만 사용하며 코드·설정 파일·로컬 저장소에 저장하지 않습니다. 이 페이지를 제3자에게 편집 권한 없이 안전하게 배포하세요.
아직 연결되지 않았습니다. 비공개 저장소와 쓰기 권한이 있는 토큰을 입력해 주세요.
저장 위치: report-data/default/. GitHub 연결 상태는 탭을 닫거나 새로고침하면 해제되며, 재연결 시 토큰을 다시 입력해야 합니다. 다른 사용자의 화면에 광고 데이터를 공개하려면 별도 인증 서버가 필요합니다.
