# 네이버 SA·GFA 통합 광고 대시보드 v4 · 안전 배포 버전

## 1. 변경 사항
- 이전 파일의 GitHub 개인 액세스 토큰(PAT) 입력창, GitHub API 요청, 자동 원격 백업 기능을 완전히 제거했습니다.
- 광고 데이터는 브라우저 IndexedDB에 광고주별로 자동 저장됩니다. 사이트는 네트워크 요청을 하지 않도록 CSP를 적용했습니다.
- **데이터 백업(JSON)** / **백업 불러오기** 버튼을 추가해 다른 PC로 정규화된 리포트 데이터를 옮길 수 있습니다. JSON 백업에는 원본 CSV/XLSX 파일 바이트는 포함하지 않습니다.
- 전주·전월·전년 비교, 우수/저조 키워드, GFA 소재, KPI, 캠페인, PDF 인쇄 기능은 유지합니다.
- 처음 열면 가상 샘플 성과가 표시됩니다. 실제 원본 로우파일과 컬럼이 맞는지 업로드 후 점검해 주세요.

## 2. GitHub Pages 배포
1. ZIP 압축 해제 후 **`index.html`과 `.nojekyll`을 GitHub Pages 저장소의 최상위 경로에 업로드**합니다. `sample_csv`는 선택 사항입니다.
2. 기존 `index.html` 파일이 있다면 같은 이름으로 **교체(덮어쓰기)** 합니다. 이전 위험 기능이 포함된 파일이나 불필요한 페이지는 배포 경로에서 삭제하세요.
3. GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택합니다.
4. `https://사용자명.github.io/저장소명/` 주소로 엽니다.
5. 배포한 사이트의 원본 HTML에 `ghToken`, `github_pat_`, `api.github.com`이 없는지 확인하세요.

> 중요: 이 버전에서는 GitHub가 **웹페이지 호스팅만** 합니다. 광고 데이터는 GitHub에 자동 저장되지 않습니다. 클라우드 백업/여러 PC 간 동기화는 별도 인증 서버와 비공개 데이터 저장소가 필요합니다.

## 3. 로우파일 업로드와 저장
1. **로우파일 업로드**를 클릭해 SA 캠페인, GFA 캠페인, SA 키워드, GFA 소재의 CSV/TSV/XLSX 파일을 선택합니다.
2. 데이터가 자동 집계되고, 브라우저에 원본과 정규화 지표가 함께 저장됩니다.
3. 광고주 추가/선택 기능으로 여러 광고주를 분리 관리할 수 있습니다.
4. **데이터 백업(JSON)** 으로 광고주 전체 데이터를 내려받고, 다른 기기에서는 **백업 불러오기**를 사용합니다.
5. CSV/XLSX 원본은 해당 PC에 별도로 보관하세요. JSON 복원에는 원본 파일 바이트가 포함되지 않습니다.

## 4. Chrome의 빨간색 '위험한 사이트' 경고가 계속 뜬다면
이 경고는 Chrome의 Safe Browsing 측에서 해당 **URL/사이트**를 분류한 결과입니다. HTML을 바꿨다고 즉시 해제되는 것은 아닙니다. **경고를 무시하거나 보호 기능을 끄고 접속하지 마세요.**

1. Google Search Console에 배포 사이트의 소유권을 확인합니다.
2. **보안 문제(Security Issues)** 보고서에서 분류 이유와 영향을 받은 URL을 확인합니다.
3. 이전 페이지나 위험한 리소스가 모두 제거됐는지 확인한 뒤, 문제가 해결됐다면 **검토 요청(Request review)** 을 제출합니다.
4. 잘못 분류된 경우 Google의 피싱 오탐 신고 경로를 이용합니다. 반영까지 시간이 걸릴 수 있습니다.

공식 안내: https://support.google.com/webmasters/answer/9044101?hl=ko

## 5. 보안 주의사항
- HTML 코드를 GitHub Pages에 공개하면 누구나 소스를 열 수 있습니다. **광고주별 실데이터, 백업 JSON, 접근 토큰을 저장소에 올리지 마세요.**
- 같은 브라우저를 공유하는 사람은 로컬 저장된 데이터를 볼 수 있습니다. 브라우저 저장소를 지우거나 시크릿 창을 종료하면 데이터가 사라질 수 있습니다.
- 이 버전은 **내부 관리자용 로컬 저장 방식**이며, 광고주 로그인/접근제어가 있는 서비스가 아닙니다.
- 네이버 SA/GFA 보고서의 전환 집계, VAT, 매출 기준이 다르면 지표 차이가 발생할 수 있습니다.
